# SAP ABAP Airline Reservation System

## Overview
This project demonstrates an Airline Reservation System developed using SAP ABAP using the SAP Flight Data Model.

## Technologies Used
- SAP ABAP
- Open SQL
- Internal Tables
- SAP Standard Tables

## Tables Used
- SCARR (Airline Master)
- SPFLI (Flight Schedule)
- SFLIGHT (Flight Details)

## Features
- Search flights
- View route information
- Display flight details
- Airline management

## Program Name
ZAIRLINE_REPORT

## Output Example

Input:

Source City : FRANKFURT
Destination City : NEW YORK

Output:

Carrier    Connection    Date       Price
LH         0400          15.07.2025 600
